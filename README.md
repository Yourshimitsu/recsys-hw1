## Данные

[GH Archive public stars September-October 2014](https://www.gharchive.org/): самостоятельно формируемая выборка исходных публичных событий `WatchEvent`, `action=started`. Файлы с 2014-09-01 по 2014-10-08 включительно. После очистки: **386,338 взаимодействий, 46,083 пользователей, 2,995 объектов**.

Метаданные — исторические язык и владелец репозитория. Карты признаков, каталог до 3 000 объектов и фильтрация активности строятся только на train. Метаданные берутся до его границы. Разбиение по времени: train до 2014-10-06T00:00:00Z, validation до 2014-10-07T00:00:00Z, затем test. Релевантность — новое будущее добавление в избранное. Все модели ранжируют весь выбранный каталог с исключением известной истории; наборы пользователей и кандидатов едины внутри каждого этапа.

Правила выборки и загрузка находятся в [data_pipeline.py](data_pipeline.py), параметры — в [config/data_config.json](config/data_config.json). Это 912 часовых архивов, примерно 8.61 ГБ по сети. Полные raw-архивы не сохраняются, только компактная локальная выборка. Ссылки и SHA-256 — [results/source_archives.json](results/source_archives.json). Данные, идентификаторы и обученные веса в GitHub не включаются.

## Запуск

Проверено на Python 3.12, CPU, четыре вычислительных потока. Из корня этой папки:

```text
python -m pip install -r requirements.txt
python data_pipeline.py --prepare
python run_experiments.py --force --no-download
python execute_notebook.py
python verify_submission.py --run-tests
```

Для интерактивной работы: `jupyter lab experiments.ipynb`. Код использует относительные пути; приватные токены и платные сервисы не требуются. Загрузка возобновляется по часовым файлам с проверкой контрольных сумм. Изменение конфигурации или подготовки инвалидирует кеш данных. Изменение кода моделей, протокола или конфигурации инвалидирует готовые результаты; `--force` всегда запускает новое обучение.

В ноутбуке для полного повторного обучения установите `RECOMPUTE_EXPERIMENTS = True`. Сохранённый отчёт содержит результаты завершённого запуска.

## Сравнение на test

Основная метрика NDCG@10 выбрана до подбора. Параметры подбирались на validation, затем все модели заново обучены на train + validation. Ниже результаты на 9,867 пользователях; все пользователи с нулём попаданий учтены.

| Модель | NDCG@10 | Recall@10 | Покрытие каталога |
|---|---:|---:|---:|
| Recency iALS | 0.08110 | 0.12640 | 0.189 |
| Popularity | 0.06414 | 0.14478 | 0.013 |
| FM IDs only | 0.06154 | 0.14504 | 0.013 |
| EASE | 0.05685 | 0.10288 | 0.506 |
| ItemKNN | 0.05212 | 0.09743 | 0.839 |
| iALS | 0.04887 | 0.09058 | 0.234 |
| FM metadata | 0.02207 | 0.03433 | 0.027 |


FM IDs only — контроль с параметрами выбранной FM и без метапризнаков. Popularity — дополнительная неперсональная база. Полный поиск: [validation_trials.csv](results/validation_trials.csv); выбранные параметры: [selected_parameters.json](results/selected_parameters.json); итог: [test_metrics.csv](results/test_metrics.csv). Парные bootstrap-интервалы эффекта метаданных и кастомного сигнала: [evaluation_details.json](results/evaluation_details.json).

## Кастомный целевой сигнал

Для наблюдённой пары `p_rec = q + (1-q) * 2**(-age_days / half_life_days)`, для ненаблюдённой `p_rec=0`. Confidence `c=1+alpha*r` и основные параметры базового iALS сохранены. Меняется правая часть нормальных уравнений, а не только confidence. Давность и нижняя граница сигнала выбраны по validation. Критерий релевантности на test остаётся единым бинарным будущим событием.

## Структура и ограничения

- `models/` — отдельные реализации пяти методов; только матричные операции и PyTorch primitives.
- `experiments.ipynb` — выполненный основной отчёт.
- `data_pipeline.py`, `evaluation.py`, `run_experiments.py` — воспроизводимые данные, единая оценка и обучение.
- `results/`, `figures/` — агрегированные результаты и графики.
- `tests/`, `verify_submission.py` — проверки математических формул, временного протокола и готовности файлов.
- `.cache_data/` — локальные данные, исключены через `.gitignore`.

Выводы относятся к активным пользователям и выбранному каталогу в одном историческом периоде. Исключённые новые пользователи и объекты отдельно посчитаны в отчёте; cold-start здесь не решается. Публичная лента может быть неполной; отсутствие звезды не доказывает отсутствие интереса. Небольшой поиск и один seed ограничивают обобщение результатов. Код GH Archive имеет MIT-лицензию, но архив событий этой лицензией не покрыт; raw-данные не распространяются с работой.
